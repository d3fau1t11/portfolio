# Certificate viewing and Green Africa Farms

The credential cards previously described the awards without linking their documents. All 21 now provide **View certificate**, a zoomable preview, **Open PDF** and **Download PDF**. The four Professional Development cards use the same viewer, with the summer camp first. Links use the `/portfolio/` base path and retain direct PDF access without JavaScript. The native dialog supports keyboard focus, Escape, backdrop dismissal and focus return; PDF access stays available if an image cannot load.

The 19 local PDFs and two certificate images were visually reviewed. Display copies correct the three sideways scans and omit three blank printer-overflow pages. Certificate identifiers, verification links and the Cisco verification QR code are removed from the copies. The original files remain local and unchanged. Each display PDF is built from the reviewed image, excluding the original metadata, annotations and recoverable identifier text. The manifest records the 21 PDFs, 21 WebP previews, dimensions and SHA-256 hashes; output verification rejects missing, modified or unreviewed assets.

On 8 November 2026, GitHub's repository metadata confirms that [Green Africa Farms](https://github.com/d3fau1t11/Green-Africa-Farms) is public. Its [README](https://github.com/d3fau1t11/Green-Africa-Farms/blob/main/README.md), [package manifest](https://github.com/d3fau1t11/Green-Africa-Farms/blob/main/package.json) and shop/cart source confirm Next.js, React, TypeScript, Tailwind CSS, catalogue search, category filters, localStorage cart persistence and WhatsApp order-message checkout. The card now uses **View repository**, links the public source and retains the [live storefront](https://green-farms.netlify.app/). Remote source was read as evidence; no changes were made to that repository.
